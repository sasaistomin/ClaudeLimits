# Claude Limits

Показывает, **сколько лимита Claude осталось**, прямо в меню-баре macOS или в трее Windows.

```
macOS:   ◔ 86%          Windows:   (86)  ← цветной кружок в трее
```

По клику открываются подробности:

- **5-часовое окно**: сколько осталось и когда сбросится;
- **неделя**: сколько осталось и когда сбросится;
- цвет по уровню расхода: 🟢 до 70% · 🟡 70–90% · 🔴 больше 90%;
- переключатель «Запускать при входе в систему»;
- выбор языка интерфейса: русский, English или как в системе;
- **уведомления**, когда осталось 20% и 5% лимита и когда лимит сбросился;
- **график расхода** за 5 часов и за неделю с **прогнозом**, когда закончится лимит при текущем темпе.

> Работает с подпиской **Claude Pro / Max / Ultra** и **Claude Code**.
> Данные берутся из официального поля `rate_limits`, которое Claude Code передаёт в statusline.
> Нет паролей, cookie и неофициальных API.

---

## Как это работает

```
Claude Code ──(после каждого ответа)──> statusline-скрипт ──> ~/.claude/limits.json ──> значок в меню-баре / трее
```

1. После каждого ответа Claude Code вызывает statusline-команду и передаёт ей JSON с полем `rate_limits` (процент использования и время сброса).
2. Наша команда сохраняет эти данные в файл `~/.claude/limits.json`. Внизу Claude Code при этом появляется строка вида `[Opus 5.5] 5h: 14% 7d: 51%`.
3. Приложение раз в 5 секунд читает этот файл и обновляет значок.

⚠️ **Важно:** цифры обновляются только во время работы **Claude Code**. Если какое-то время пользоваться только claude.ai в браузере, значок покажет последние известные данные (в меню видно, когда они обновились). После времени сброса окно автоматически считается обнулённым.

## Установка на macOS

**Требования:** macOS 13 (Ventura) или новее, установленный [Claude Code](https://claude.com/claude-code).

### Вариант 1: одной командой

Откройте **Терминал** и вставьте:

```bash
curl -fsSL https://raw.githubusercontent.com/sasaistomin/ClaudeLimits/main/macos/install.sh | bash
```

### Вариант 2: из скачанного архива

1. Нажмите зелёную кнопку **Code → Download ZIP** на этой странице и распакуйте архив.
2. Откройте Терминал в распакованной папке и выполните:
   ```bash
   bash macos/install.sh
   ```

### Что делает установщик

- Собирает приложение из исходника (около 30 секунд). Если в системе нет компилятора Swift, откроется окно установки **Xcode Command Line Tools**: согласитесь, дождитесь окончания и запустите установщик ещё раз.
- Кладёт приложение в `~/Applications/ClaudeLimits.app`.
- Прописывает statusline в `~/.claude/settings.json`. Старый файл сохраняется как `settings.json.bak`.
- Запускает приложение: справа вверху появится значок ◔ с процентом.

> Приложение собирается на вашем компьютере, поэтому macOS не показывает предупреждение «разработчик не проверен».

## Установка на Windows

**Требования:** Windows 10 или 11, установленный [Claude Code](https://claude.com/claude-code). PowerShell уже встроен в Windows, больше ничего ставить не нужно.

### Вариант 1: одной командой

Откройте **PowerShell** или **командную строку** (Пуск → введите «PowerShell» или «cmd») и вставьте:

```
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/sasaistomin/ClaudeLimits/main/windows/install.ps1 -OutFile $env:TEMP\cl-install.ps1; & $env:TEMP\cl-install.ps1"
```

### Вариант 2: из скачанного архива

1. Нажмите **Code → Download ZIP** на этой странице и распакуйте архив.
2. Откройте PowerShell в распакованной папке и выполните:
   ```powershell
   powershell -ExecutionPolicy Bypass -File windows\install.ps1
   ```

### Что делает установщик

- Копирует файлы в `%LOCALAPPDATA%\ClaudeLimits`.
- Прописывает statusline в `%USERPROFILE%\.claude\settings.json`. Старый файл сохраняется как `settings.json.bak`.
- Добавляет ярлык в «Автозагрузку», чтобы значок запускался вместе с Windows.
- Запускает значок в трее (справа внизу; если его не видно, нажмите стрелку **^**).

> Совет: чтобы значок всегда был на виду, перетащите его из-под стрелки **^** на панель задач.

## Как пользоваться

1. После установки **отправьте любое сообщение в Claude Code**: после первого ответа появятся цифры.
2. **Число на значке** показывает, сколько процентов осталось в текущем 5-часовом окне.
3. **Клик по значку** открывает подробности: 5 часов, неделя, время до сброса, когда обновлялись данные.
4. Цвет и иконка подсказывают уровень расхода: зелёный — всё хорошо, жёлтый — израсходовано больше 70%, красный или ⚠ — больше 90%.
5. **Автозапуск** включается и выключается галочкой в том же меню.
6. **Язык** выбирается в том же меню: «Системный» (как в системе), «Русский» или «English». Выбор запоминается.
7. **Уведомления** включены по умолчанию и выключаются галочкой «Уведомления» в меню. Приходят:
   - «Claude: осталось 20%», когда окно израсходовано на 80%;
   - «Claude: осталось 5%», когда окно израсходовано на 95%;
   - «Лимит Claude сброшен», если до сброса окно было израсходовано на 80% и больше.

   Каждое уведомление приходит один раз за окно, отдельно для 5-часового и недельного лимита. На macOS при первом запуске система спросит разрешение: нажмите «Разрешить». Если уведомления не приходят, проверьте «Системные настройки → Уведомления → ClaudeLimits» (macOS) или «Параметры → Система → Уведомления» (Windows).
8. **График.** На macOS он находится в окне по клику на значок, на Windows — в пункте меню «График использования…». Переключатель **«5 часов / Неделя»** выбирает окно. На графике:
   - синяя ступенчатая линия показывает, как рос расход в текущем окне;
   - серый пунктир — прогноз при текущем темпе;
   - красная пунктирная линия — лимит 100%;
   - при наведении мышью видно, сколько было израсходовано в выбранный момент.

   Под графиком подпись: «Прогноз: при таком темпе лимит закончится в 16:40» или «…лимита хватит до сброса». История копится с момента установки, поэтому в первые часы график будет почти пустым.
9. **Выход** — кнопка «Выйти» (macOS) или «Выход» (Windows) в меню.

Чтобы запустить приложение снова после выхода:
- **macOS:** откройте `~/Applications/ClaudeLimits.app` или найдите «ClaudeLimits» через Spotlight.
- **Windows:** перезапустите установщик или просто перезагрузите компьютер, если включён автозапуск.

## Удаление

**macOS:**
```bash
bash macos/uninstall.sh
```
Если архива с проектом уже нет:
```bash
~/Applications/ClaudeLimits.app/Contents/MacOS/ClaudeLimits --uninstall; rm -rf ~/Applications/ClaudeLimits.app
```

**Windows:**
```powershell
powershell -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\ClaudeLimits\uninstall.ps1"
```

Удаление убирает приложение, автозапуск и строку `statusLine` из `settings.json`.

## Частые вопросы

**Значок показывает «—» или «нет данных».**
Отправьте сообщение в Claude Code и дождитесь ответа. Если не помогло:
- проверьте, что вы вошли в Claude Code через подписку Pro/Max/Ultra (команда `/login`). При работе через API-ключ поля `rate_limits` нет;
- проверьте, что внизу Claude Code появилась строка `[Модель] 5h: …%`. Если её нет, перезапустите Claude Code.

**У меня уже был свой statusline. Он пропал?**
Установщик заменяет его, но сохраняет копию в `~/.claude/settings.json.bak`. Вернуть старый statusline можно, удалив Claude Limits.

**Это безопасно?**
Да. Приложение только читает локальный файл и ничего не отправляет в интернет. Весь код открыт и находится в этом репозитории.

**Цифры отличаются от claude.ai.**
Claude Code получает данные после каждого своего ответа. Если вы тратили лимит в браузере, цифры обновятся при следующем ответе Claude Code.

## Структура проекта

```
macos/
  Core.swift             логика: statusline, установка, история, прогноз, правила уведомлений, тексты
  App.swift              интерфейс: меню-бар (SwiftUI), график (Swift Charts), уведомления
  install.sh             сборка и установка
  uninstall.sh           удаление
windows/
  ClaudeLimits.Core.ps1  логика (то же, что Core.swift)
  ClaudeLimits.ps1       значок в трее (WinForms), окно с графиком (GDI+)
  statusline.ps1         statusline-команда для Claude Code
  install.ps1            установка
  uninstall.ps1          удаление
tests/
  smoke.sh               smoke-тест: быстрая проверка главного (≈10 секунд)
  run-all.sh             все тесты, доступные на этом компьютере
  macos/                 юнит-тесты (UnitTests.swift) и интеграционные (integration.sh)
  windows/smoke.ps1      smoke-тест Windows
  windows/run-tests.ps1  тесты Windows-версии (логика, statusline, установка, значок, удаление)
.github/workflows/tests.yml  автопроверка на macOS, Windows (PowerShell 5.1 и 7) и Linux при каждом push
```

## Тесты

Smoke-тест: за несколько секунд проверяет главное (установка → строка статуса → окно → удаление):

```bash
bash tests/smoke.sh                  # macOS
SMOKE_REMOTE=1 bash tests/smoke.sh   # + файлы на GitHub совпадают с локальными
```

На Windows: `powershell -NoProfile -ExecutionPolicy Bypass -File tests\windows\smoke.ps1`

Все тесты:

```bash
bash tests/run-all.sh
```

- **macOS:** юнит-тесты логики и интеграционные тесты. Приложение по-настоящему устанавливается во временную папку (ваши настройки не затрагиваются), проверяются statusline, история, повторная установка, установка со скачиванием, запуск, отрисовка окна и удаление.
- **Windows:** `powershell -NoProfile -ExecutionPolicy Bypass -File tests\windows\run-tests.ps1`. Проверяются логика, statusline, установка, команда из `settings.json` через cmd и Git Bash, самопроверка значка в трее с отрисовкой графика и удаление.
- **GitHub Actions** запускает всё это при каждом push на macOS, Windows (PowerShell 5.1 и 7) и Linux. Результаты на вкладке **Actions** в репозитории.

Формат `~/.claude/limits.json` одинаков на обеих системах:

```json
{
  "updated_at": 1795436426,
  "model": "Opus 5.5",
  "rate_limits": {
    "five_hour": { "used_percentage": 14, "resets_at": 1795450200 },
    "seven_day": { "used_percentage": 51, "resets_at": 1795557600 }
  }
}
```

История для графиков хранится в `~/.claude/limits-history.jsonl`: одна строка на каждое изменение процентов, хранятся последние 8 дней:

```json
{"t":1795466653,"f":7,"fr":1795482600,"w":53,"wr":1795557600}
```
